Una API, tres formas de consultar

El mismo endpoint responde a GET, POST y al método experimental QUERY.

GET

/api/tipo-cambio

Consulta directa del tipo de cambio actual del día.

Sin parámetros
POST

/api/tipo-cambio

Envía un monto en dólares y recibe el equivalente en quetzales.

Envía JSON
QUERY

/api/tipo-cambio

Método HTTP experimental con un comportamiento similar a POST.

Método experimental

Pruébalo

Ejecuta consultas reales contra la API y revisa la respuesta JSON al instante.

Experimentando con HTTP

Esta prueba de concepto explora cómo Lenguaje Quetzal expone métodos clásicos y experimentales.

GET

  • Lectura de recursos
  • Sin cuerpo en la petición
  • Idempotente y cacheable
  • Ideal para consultar el tipo del día
VS

POST

  • Envía datos en el cuerpo
  • Útil para conversiones
  • JSON con valor_dolares
  • Amplio soporte en clientes
VS

QUERY

  • Método HTTP experimental
  • Comportamiento similar a POST
  • Demuestra flexibilidad del runtime
  • Pensado para explorar Quetzal
